# Build this game

Build the game this repository describes, in Godot 4.7.2.

Read README.md, then every file in specs/, starting with
specs/overview.md. The specs are the whole brief: build what they
describe, the way they describe it, with the art in art/, the music in
music/ and the sounds in sounds/. Write the acceptance tests the specs
give, and make them pass.

The levels are yours to design: be creative, and use the biomes, enemies
and everything else the specs offer.

When you believe the game is complete and working, say so, and say how
to play it.
