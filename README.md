# Platformer

A small 2D platformer for Godot 4.7.2, written first as a full spec, to be
built from that spec by Claude.

- `specs/`: the spec, one file per mechanic. Start with `specs/overview.md`.
- `art/`: the sprites and tiles.
- `music/`: the music.
